# lenovo-fn-osd

> ⚠️ **AI-Generated Notice**: This program was generated by AI. If you are concerned about AI-generated content, please use it with caution.

Show **native-looking OSD popups** on KDE Plasma (works on both Wayland and X11) for the Fn key combinations of Lenovo laptops.

Tested and verified on a ThinkBook 16 G4+ IAP (Ubuntu 26.04 + Plasma 6.6.6, Wayland).

## Features

| Key | Popup content | Implementation |
|---|---|---|
| Fn+Q | Power profile: Performance / Balanced / Power Saver | Watches `/sys/firmware/acpi/platform_profile` (`low-power` is normalized to `power-saver`) |
| Caps Lock | Caps Lock On / Off | Watches `/sys/class/leds/*capslock*/brightness` |
| Num Lock | Num Lock On / Off | Watches `/sys/class/leds/*numlock*/brightness` |
| Fn+Esc | Fn Lock On / Off | Watches `/sys/class/leds/*fnlock*/brightness` |

> Touchpad toggle (Fn+M / Fn+F7) and keyboard backlight (Fn+Space) already ship with native OSD in KDE Plasma 6, so this daemon does not handle them again.

## How it works

- Fn+Q / Fn+Esc / Fn+Space / Fn+M are handled directly by the laptop firmware (EC) and **do not** generate keyboard events (confirmed: the ideapad input device does not report these keys on this machine). They only surface in sysfs: the power profile in `platform_profile`, and the Fn/Caps/Num lock states in the LED brightness nodes. Hence a lightweight poll (default 0.25 s, reading a few bytes) detects the changes.
- Popups are shown through plasmashell's `org.kde.osdService` DBus interface (`powerProfileChanged` / `showText`), identical in look to system popups (volume, brightness, backlight, etc.). Falls back to `notify-send` when plasmashell is unavailable.
- When the user presses KDE's built-in "Switch Power Profile" shortcut (default **Meta+B**), PowerDevil shows its own OSD; the daemon listens to kglobalaccel and suppresses its own duplicate popup for 1.5 s after that shortcut fires.

## Installation

```bash
cd lenovo-fn-osd
./install.sh        # copies to ~/.local/bin, registers and starts a systemd user service
```

After installation, press Caps Lock / Num Lock / Fn+Esc / Fn+Q to see the popups.

## Self-test

- Power profile: with the service running (`systemctl --user status lenovo-fn-osd`), press Fn+Q; or switch the profile through power-profiles-daemon and a popup appears too:
  ```bash
  gdbus call --system --dest net.hadess.PowerProfiles --object-path /net/hadess/PowerProfiles \
    --method org.freedesktop.DBus.Properties.Set net.hadess.PowerProfiles ActiveProfile "<'balanced'>"
  ```
- Verify the logic without a GUI (simulate LEDs with temporary files):
  ```bash
  printf 0 > /tmp/caps; LENOVO_OSD_CAPS=/tmp/caps python3 lenovo-fn-osd.py --debug
  # in another terminal: printf 1 > /tmp/caps   →  should print OSD text: icon='keyboard-caps-locked' ...
  ```

## Debugging

```bash
journalctl --user -u lenovo-fn-osd -f          # service logs
python3 ~/.local/bin/lenovo-fn-osd.py --debug  # run in foreground (stop the service first)
```

Environment variables (for debugging/adapting): `LENOVO_OSD_PROFILE`, `LENOVO_OSD_CAPS`, `LENOVO_OSD_NUM`, `LENOVO_OSD_FN` (override detection paths), `LENOVO_OSD_POLL` (poll interval in seconds), `LENOVO_OSD_SUPPRESS` (de-dup window in seconds).

## Uninstall

```bash
systemctl --user disable --now lenovo-fn-osd
rm -f ~/.local/bin/lenovo-fn-osd.py ~/.config/systemd/user/lenovo-fn-osd.service
systemctl --user daemon-reload
```

## Notes

- KDE's native "Switch Power Profile" popup (not Fn+Q, only triggers via its shortcut):
  System Settings → Shortcuts → Power Management → **Switch Power Profile** (default Meta+B / Battery key).
- Only reads sysfs; no root required; no special Wayland dependency.
